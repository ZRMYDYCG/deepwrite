# 前端闪烁问题排查与修复

## 2026-10-02：书名候选点击「采用」时闪烁

### 现象与复现

在「更多功能 → 书名·简介·封面」生成书名候选，点击候选下方的「采用」。保存过程中，多张候选卡的按钮同时变淡，保存结束后恢复；按钮文字变为「已采用」时，后面的「以此再生成」还会发生横向移动。在操作区接近换行宽度时，文字宽度变化可能引发换行和卡片高度变化。

采用书名只保存 `book-identity/identity.json` 中的采用信息；作品改名仍通过概览中的「改为此名」执行。

### 确认的原因

1. **把短暂保存锁与不可用状态合并为 `disabled`。** `useBookIdentity.mutate()` 在异步保存前将 `saving` 设为 `true`，`IdentityRoundList` 将 `!writable || saving` 传给所有候选。`book-identity.css` 的 `.book-identity-page button:disabled` 将透明度设为 `0.45`，所以一次采用会让整批操作按钮经历「正常 → 半透明 → 正常」。生成按钮、手动添加和清理按钮也受保存状态影响。
2. **状态文字的占位宽度不稳定。** 原来的采用按钮直接在「采用」与「已采用」之间切换文本，没有预留两种文案的最大宽度。操作区使用允许换行的 flex 布局，文本变长会推动后续按钮；临界宽度下还可能产生高度变化。
3. **已有检查没有覆盖中间状态和操作区位置。** 原先的采用冒烟只比较操作前后的概览高度、图片地址与候选节点是否仍连接。保存中的透明度变化在检查时已经恢复，按钮横向位移也没有被测量，因此检查通过仍可能看到闪烁。

修复前的真实 Electron 冒烟使用隔离工作区和 Faux 服务，通过 `MutationObserver` 与 `requestAnimationFrame` 连续采样。首次采用书名得到：

| 指标                    |       修复前观测 |
| ----------------------- | ---------------: |
| 采样次数                |                8 |
| 捕获到保存锁的采样次数  |                3 |
| 按钮透明度下降          | 0.55（1 → 0.45） |
| 按钮最大几何位移        |     12.859375 px |
| 概览高度变化            |             0 px |
| 滚动位置变化            |             0 px |
| 候选节点重建 / 图片重载 |            0 / 0 |

这次复现的直接原因是按钮样式和布局变化；没有观察到候选列表重建或图片重载。

### 修复方式

- 分开传递 `disabled`（权限、缺少图片等不可用条件）和 `saving`（短暂保存锁）。保存期间继续使用原生 `disabled` 阻止点击，只对因保存临时禁用的控件加 `identity-save-pending`，保持透明度为 `1`，通过等待光标和 `aria-busy` 表达正在保存。真正不可用的控件继续使用禁用样式。
- 书名、简介和封面共用 `IdentityAdoptButton.vue`。把两种文案放在同一个 grid 单元格中，以不可见且 `aria-hidden` 的占位文本撑出最大宽度，状态切换只改变可见文字。占位随语言和字号自动变化，无需固定像素宽度。
- `mutate()` 在写入尚未结束时拒绝重复写入，避免界面更新前的连点或其他入口并发提交。候选记录保留到保存成功；保存失败通过 toast 提示，仍保留原采用状态。
- 冒烟在完整点击周期中监测按钮透明度与几何位置、概览高度、滚动位置、候选节点和图片地址，并确认实际捕获了保存中的状态。

### 验证记录

- 相关 Renderer 与 Core 测试共 **7 个文件、41 项测试通过**，包括保存失败保留候选与原采用状态、过期读写结果不覆盖新版本、跨作品异步归属，以及新增的保存期间阻止重复写入。
- 完整 `pnpm typecheck`、本次改动文件的 ESLint / 格式检查，以及 `pnpm lint:boundary` 通过。
- 真实 Electron 冒烟通过：书名、简介、封面的首次采用共 3 次；在浅色、深色（14px / 1200px 窗口）和紧凑大字号（24px / 1120px 窗口）下各执行切换书名、恢复原书名、再次采用原书名，共 9 次。
- 上述 **12 次交互**均捕获了保存锁。按钮透明度变化、按钮几何位移、概览高度变化、滚动位移、候选重建与图片重载全部为 **0**；原本不可用按钮的透明度变化也为 **0**。同时验证生成、采用、改名、排版和图片协议经真实 Preload / Main / Utility 完成，并核对作品目录内的持久化记录。
- Electron 使用临时工作区与本地 Faux 服务，没有调用实际模型服务。视觉检查覆盖自定义强调色、深浅主题、24px UI 字号、四种封面排版及图片模型设置页。

### 后续排查原则

遇到「点击后闪一下」时，检查保存/加载标记是否批量改变透明度、背景或布局；状态文案和图标切换是否改变控件尺寸；刷新时是否清空已有记录或改变组件 key；图片缓存参数是否随无关 revision 变化。用过程采样区分视觉样式变化、布局位移与节点重建，不能仅凭保存前后截图相同判定没有闪烁。
